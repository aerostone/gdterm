# SSH 私钥登录

## 新建连接

1. 在“新建连接”中选择 SSH，填写主机、端口和用户名。
2. 点击“使用 SSH 私钥…”。打开的凭据表单会带入当前连接信息。
3. 点击“浏览…”，选择私钥文件，例如 `id_ed25519`、`id_rsa` 或 PEM 文件。不要选择 `.pub` 公钥。
4. 加密私钥需要填写“密钥口令”；未加密的私钥留空。这里填写的是私钥口令，不是服务器登录密码。
5. 保存凭据表单后，连接页显示“待保存…（SSH 私钥）”。点击连接页“创建”或“保存”才会写入密码库并绑定连接；取消连接窗口不会保存这份待提交的密钥。

## 已有凭据与密钥更换

- 可在“密码库管理 → 添加”中把“认证方式”设为“SSH 私钥”，也可在连接的“选择凭据… → 新建”中创建。
- 已导入的密钥在选择列表和连接页标注“SSH 私钥”；选中后，SSH 登录使用该条目的私钥及口令。
- 密码库“编辑”会恢复已保存的密钥和口令，无需保留原始文件。点击“浏览…”可替换私钥，同时填写新私钥对应的口令。
- 切回“密码”并保存，会移除该条目的私钥附件及私钥口令。仅修改标题、分组等其他字段会保留密钥。
- 原“工具 → SSH 密钥管理”入口仍可导入密钥，使用同一套私钥格式与口令校验。

私钥内容和口令保存在加密的 KeePass 密码库中，连接配置仅保存凭据引用。导入成功后原私钥文件可移动，应用使用密码库中的副本。服务器需要事先授权对应的公钥；导入到本地密码库不会修改服务器的 `authorized_keys`。

## 验证范围

回归覆盖 OpenSSH Ed25519（未加密和加密）、RSA PEM、公钥误选、错误口令、真实 KDBX 重新打开、自动匹配、显式选择、文件夹继承及代理连接信息构建。Windows 界面测试覆盖新建、取消、保存失败重试、重新编辑、切回密码和重新打开连接。

这些检查验证本地凭据流程和 SSH.NET 认证参数；不代表已用用户的服务器和密钥完成实机登录。

## SSH 跳板与多跳

在连接的高级设置中启用“使用 SSH 隧道（跳板机）”，点击“添加跳板”。每台跳板填写主机、端口，并选择自己的密码或 SSH 私钥凭据；用户名留空时使用凭据中的用户名。可用上移、下移调整连接顺序。

跳板弹窗的“新建凭据…”支持密码和私钥。新条目先保留为草稿，点击外层连接的保存才写入密码库；取消丢弃草稿。保存失败会保留未完成的草稿以便重试。

旧连接的跳板如果尚未绑定凭据，需要编辑后补选。程序不会把目标服务器的密码或密钥自动发送给跳板；要共用同一凭据，请在跳板中显式选择同一条目。删除凭据或锁定密码库后会提示认证信息不可用。

终端、SFTP 和 RDP 均使用配置的跳板链；代理作用于首台跳板。中间跳板转发在整条连接存活期间保持，检测到跳板断线后，重连会重新建立隧道。

自动回归使用隔离的本地 OpenSSH 服务验证两跳命令、HTTP CONNECT 代理、失效重建、并发建立和关闭竞争。它不代表已验证用户的具体网络或服务器配置。
